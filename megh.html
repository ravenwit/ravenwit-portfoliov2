Cryptographic Architecture
Zero-Knowledge, Defense in Depth
Five cryptographic algorithms working in concert to ensure that no one — not even us — can access your data.
🔑 Master Password

Never stored. Exists only in your memory.

Argon2id (256 MB, 4 iter)

Password → 256-bit Master Key

MK_meta

HKDF → Encrypts filenames, DEKs, tokens

MK_auth

HKDF → Verifies key correctness

MK_recov

Shamir SSS → 3-of-5 recovery shares

Upload Encryption Flow
01
Generate Unique File Key
Each file gets a random 256-bit Data Encryption Key (DEK). Wrapped with AES-256-GCM using your Master Key.
DEK = crypto.getRandomValues(32 bytes)
wrapped = AES-256-GCM(MK_meta, DEK)
02
Content-Defined Chunking
FastCDC splits the file at content-derived boundaries (avg 8 MB). Changing 1 byte affects only 1 chunk — enabling delta sync.
chunks = FastCDC(file, min=4MB, avg=8MB, max=16MB)
03
Encrypt Each Chunk
XChaCha20-Poly1305 with a unique 192-bit nonce per chunk. AEAD provides both confidentiality and integrity.
nonce = random(24 bytes)
encrypted = XChaCha20-Poly1305(DEK, nonce, chunk)
04
Integrity Hashing
BLAKE3 hash computed on each encrypted chunk for verification during download. Tree-hashable for parallel computation.
hash = BLAKE3(encrypted_chunk)
05
Allocate to Providers
Megh API assigns chunks to providers based on available space and health scores. Weighted allocation prevents overload.
POST /api/v1/files/upload/init → allocation map
06
Direct-to-Provider Upload
Encrypted chunks upload directly from your device to each cloud provider. Megh's servers never touch file data — zero bandwidth cost.
Client → Google Drive (chunk 0, 1, 2)
Client → Backblaze B2 (chunk 3, 4)
Defense in Depth
🔐

XChaCha20-Poly1305

192-bit nonce eliminates reuse risk even with billions of chunks. Fast in pure software — no hardware needed.

🧠

Argon2id (256 MB)

Memory-hard KDF. 1000 GPUs need 30 years to crack an 8-char password. We enforce 12-char minimum.

🧩

Shamir Secret Sharing

3-of-5 threshold recovery. Information-theoretically secure — not even quantum computers can break it with 2 shares.

🔍

BLAKE3 Integrity

Fastest cryptographic hash. Verifies every chunk on download. Detects corruption, tampering, or bit rot.

🗂️

Per-File Keys

Unique 256-bit DEK per file. Compromising one key affects one file only — blast radius containment.

👻

Zero-Knowledge Server

Megh sees encrypted blobs. Providers see encrypted noise. Even a total server breach reveals nothing usable.
